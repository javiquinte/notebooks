# GEOFON Notebooks

This repository provides Jupyter Notebooks to access DAS data with examples that should allow
you to make full use of it and the GEOFON services.

## Quick start
You can install all these notebooks by just cloning this repository. By doing that,
you can edit them to have a more personalized approach for your use cases, and even to
add personal information to the code. For instance, access tokens, paths to your files, etc.

    $ git clone https://git-int.gfz-potsdam.de/javier/geofon-notebooks.git

If you want only to run tany of these, you can do it directly from [mybinder.org](https://mbinder.org)
